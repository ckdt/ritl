# Ronny in the Loop

Tijdelijke landingspagina met het Ronny in the Loop-logo.

- De tekstring draait langzaam tegen de klok in.
- Het oog volgt de muis (of je vinger op mobiel) en blijft binnen de oogkas.
- Af en toe knippert het oog; zonder input kijkt het zelf wat rond.
- Met "minder beweging" aan staat alle animatie stil.

Alles zit in één bestand, `index.html`, zonder externe afhankelijkheden.
Werkt direct op GitHub Pages of elke statische host.
